Setup

Machine bootstrap

Bootstrap any machine into G-System. One command on Mac, one command on Linux. An agent can read and execute this page directly.

Mac genv-mac

Clone the Mac overlay and run bootstrap. It auto-clones the base genv repo alongside, wires claude, codex, git, zsh, Ghostty, and SSH, then installs a settings.local.json template.

1. Clone and bootstrap

git clone https://github.com/Volcanex/genv-mac ~/genv-mac
bash ~/genv-mac/bootstrap.sh

If bootstrap fails on a missing sync-ecc.sh, delete the line that calls it from ~/genv-mac/bootstrap.sh. ECC was removed (2026-06-16); skills are tracked directly now (step 4).

2. Secrets: Brain MCP credentials

Copy the example env file and fill in the Cloudflare Access service-token pair for the Brain MCP. Get the values from gcore passport.

cp ~/genv-mac/.env.example ~/genv-mac/.env
# edit ~/genv-mac/.env:
#   CF_ACCESS_CLIENT_ID=...
#   CF_ACCESS_CLIENT_SECRET=...

Add source ~/genv-mac/.env to the bottom of your ~/.zshrc (or it goes in genv-mac/zsh/zshrc if you want it tracked).

3. settings.local.json: machine-specific Claude Code overrides

The base ~/.claude/settings.json is now symlinked from genv. Machine-specific config (permissions mode, Brain MCP connection, Playwright) goes in ~/.claude/settings.local.json which is not tracked.

{
  "permissions": {
    "defaultMode": "auto",
    "skipAutoPermissionPrompt": true
  },
  "mcpServers": {
    "brain": {
      "type": "sse",
      "url": "",
      "headers": {
        "CF-Access-Client-Id": "<CF_ACCESS_CLIENT_ID>",
        "CF-Access-Client-Secret": "<CF_ACCESS_CLIENT_SECRET>"
      }
    },
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}

Playwright MCP gives Claude Code a headed browser with visual feedback. Install Node if needed: brew install node.

4. Skills

Skills are a small curated set tracked directly in genv: g-gcore-comply plus a few pinned upstream skills. They arrive via the ~/.claude/skills symlink after bootstrap; nothing to run. To refresh the pinned upstream skills later: bash ~/genv/scripts/vendor-skills.sh. (ECC was removed 2026-06-16; keep the library lean.)

5. Auto-sync (launchd)

The Mac has no systemd, so it needs a launchd agent to self-update daily, the Mac equivalent of the Linux genv-sync.timer. Create the LaunchAgent and load it:

cat > ~/Library/LaunchAgents/com.gabriel.genv-sync.plist <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.gabriel.genv-sync</string>
  <key>ProgramArguments</key><array>
    <string>/bin/bash</string><string>-lc</string>
    <string>cd ~/gcore && git pull --ff-only; cd ~/genv && git pull --ff-only; cd ~/genv-mac && git pull --ff-only && bash bootstrap.sh</string>
  </array>
  <key>StartCalendarInterval</key><dict><key>Hour</key><integer>9</integer><key>Minute</key><integer>30</integer></dict>
  <key>RunAtLoad</key><true/>
  <key>StandardOutPath</key><string>/tmp/genv-sync.log</string>
  <key>StandardErrorPath</key><string>/tmp/genv-sync.err</string>
</dict></plist>
PLIST
launchctl load -w ~/Library/LaunchAgents/com.gabriel.genv-sync.plist

Daily at 09:30 and on login: pulls gcore/genv/genv-mac and re-bootstraps. Logs to /tmp/genv-sync.*. Adjust paths if your repos live elsewhere.

6. Verify

# Check symlinks landed
ls -la ~/.claude/settings.json ~/.claude/skills ~/.claude/agents

# Curated skills + agents present
ls ~/.claude/skills    # ~5: g-gcore-comply + vendored
ls ~/.claude/agents    # g-executor, g-explore

# Launch Claude Code; Brain MCP and skills should be available
claude

Linux / Ubuntu genv-linux

Clone the Linux overlay and run bootstrap. Auto-clones base genv, wires claude/codex/git, creates settings.local.json with server defaults, installs the self-maintaining systemd sync timer.

1. Clone and bootstrap (run as the user who will run agents: root or your login user)

git clone https://github.com/Volcanex/genv-linux ~/genv-linux
GENV_DIR=~/genv bash ~/genv-linux/bootstrap.sh

2. settings.local.json: Brain MCP + machine overrides (not tracked)

The base ~/.claude/settings.json is symlinked from genv. Brain MCP and machine-specific overrides go in ~/.claude/settings.local.json. Fill the CF Access service-token pair from the gcore passport.

{
  "permissions": { "defaultMode": "bypassPermissions" },
  "env": { "IS_SANDBOX": "1" },
  "mcpServers": {
    "brain": {
      "type": "sse",
      "url": "",
      "headers": {
        "CF-Access-Client-Id": "<CF_ACCESS_CLIENT_ID>",
        "CF-Access-Client-Secret": "<CF_ACCESS_CLIENT_SECRET>"
      }
    }
  }
}

3. Skills

Tracked directly in genv and delivered via the ~/.claude/skills symlink; nothing to run. (ECC removed 2026-06-16; refresh pinned skills with bash ~/genv/scripts/vendor-skills.sh.)

4. Verify

# Timer self-maintains the host
systemctl status genv-sync.timer
systemctl start genv-sync.service && journalctl -u genv-sync.service -n 20

# Symlinks + curated set landed
readlink ~/.claude/hooks       # -> ~/genv/claude/hooks
ls ~/.claude/skills            # ~5: g-gcore-comply + vendored
ls ~/.claude/agents            # g-executor, g-explore

Timer fires daily with a random 0-60 min offset so servers don't hit GitHub simultaneously. Pushes to Volcanex/genv propagate overnight; the sync re-runs bootstrap-base.sh, which repairs any drifted symlinks.
